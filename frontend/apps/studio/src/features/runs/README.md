# runs

## Overview

Run list/detail presentation, live graph and journal following, operator decisions, and authorized payload views.

## Invariants

- URL filters accept enumerated run statuses and UUID-shaped workflow IDs; pasted run IDs normalize only when UUID-shaped. Start/signal payloads must be JSON objects within 256 KiB; unchanged request fingerprints retain their retry key. [frontend/apps/studio/src/features/runs/RunsPage.tsx:readFilters] [frontend/apps/studio/src/features/runs/RunsPage.tsx:parseRunId] [frontend/apps/studio/src/features/runs/StartRun.tsx:parseInput] [frontend/apps/studio/src/features/runs/StartRun.tsx:StartForm] [frontend/apps/studio/src/features/runs/SendSignal.tsx:SignalForm]
- Trace links require a nonzero 32-hex trace ID, exactly one placeholder, no whitespace/credentials, and HTTPS except HTTP loopback. [frontend/apps/studio/src/features/runs/TraceLink.tsx:traceLink]
- Attempt events are sequence-sorted and deduplicated; the first terminal event fixes the outcome. Full cards apply through 1,000 nodes and table-first above 10,000, with large-graph minimap/edge-label reductions. [frontend/apps/studio/src/features/runs/attempts.ts:ordered] [frontend/apps/studio/src/features/runs/attempts.ts:buildHistory] [frontend/apps/studio/src/features/runs/canvas.ts:FULL_CARDS_UP_TO] [frontend/apps/studio/src/features/runs/canvas.ts:TABLE_FIRST_ABOVE] [frontend/apps/studio/src/features/runs/canvas.ts:viewPolicy]
- Journal pages/live entries deduplicate by sequence. Live entries remain hidden until paged coverage is complete, default live retention is 5,000, and loadAll defaults to 50 pages. [frontend/apps/studio/src/features/runs/journal.ts:JournalStore] [frontend/apps/studio/src/features/runs/journal.ts:LIVE_CAP] [frontend/apps/studio/src/features/runs/journal.ts:MAX_PAGES]
- Live graph gaps trigger whole-graph reloads at least the configured/default two seconds apart; pending updates are bounded to 200. [frontend/apps/studio/src/features/runs/liveRun.ts:LiveRunStore.#reloadSoon] [frontend/apps/studio/src/features/runs/liveRun.ts:LiveRunStore.#enqueue] [frontend/apps/studio/src/features/runs/liveRun.ts:QUEUE_LIMIT] [frontend/apps/studio/src/features/runs/liveRun.ts:RELOAD_GAP_MS]
- Operations require permission and eligible state; potentially repeated unknown-outcome effects need saga:override. Reasons have 8–2,000 trimmed characters, and step reasons are one-line plain text. [frontend/apps/studio/src/features/runs/ops.ts:runOperations] [frontend/apps/studio/src/features/runs/ops.ts:stepOperations] [frontend/apps/studio/src/features/runs/ops.ts:checkReason]
- Run lists refresh every five seconds only while visible and expose at most 5,000 newest items by default. [frontend/apps/studio/src/features/runs/runList.ts:REFRESH_MS] [frontend/apps/studio/src/features/runs/runList.ts:MAX_ITEMS] [frontend/apps/studio/src/features/runs/runList.ts:RunListStore]
- Without run:read, the route renders NotAllowed before creating run stores or requests. RunDetail is keyed by runId so stores, selection, and dialogs do not carry across runs. [frontend/apps/studio/src/features/runs/RunDetailPage.tsx:RunDetailPage]
- The graph disables dragging, connecting, edge focus, and Delete; table and graph-skip alternatives remain available. [frontend/apps/studio/src/features/runs/GraphView.tsx:GraphView]
- Operation facts are recomputed from live state. Changed facts require renewed review; the first submission pins the seen run version, and an identical serialized retry reuses its idempotency key. [frontend/apps/studio/src/features/runs/OperationDialog.tsx:facts] [frontend/apps/studio/src/features/runs/OperationDialog.tsx:DecisionForm]
- Payload disclosure is scoped by tenant, subject, namespace, run, selector, and session identity; scope changes abort and clear state. PII needs separate confirmation and a server-granted revealPii operation. [frontend/apps/studio/src/features/runs/PayloadDisclosure.tsx:PayloadDisclosureView]
- Inspection requires run:payload:inspect, stays outside the query cache, and renders structure without original field names or scalar values. Node payload controls use journal sequence selectors and require non-null payloadRef. [frontend/apps/studio/src/features/runs/PayloadInspection.tsx:PayloadInspector] [frontend/apps/studio/src/features/runs/PayloadInspection.tsx:StructureNode] [frontend/apps/studio/src/features/runs/NodePanel.tsx:NodePanel]
- The shared clock stops advancing while hidden; finished consumers can disable ticking. [frontend/apps/studio/src/features/runs/Now.tsx:NowProvider]

## Side Effects

- Run lists fetch pages, install visibility listeners, schedule refresh timers, publish snapshots, and announce loads. [frontend/apps/studio/src/features/runs/RunsPage.tsx:RunList] [frontend/apps/studio/src/features/runs/runList.ts:RunListStore]
- StartRun posts runs, announces success, closes its dialog, and navigates to the new run; SendSignal posts a named signal and announces delivery. [frontend/apps/studio/src/features/runs/StartRun.tsx:StartForm] [frontend/apps/studio/src/features/runs/SendSignal.tsx:SignalForm]
- Timeline pages/loads journal history and polls lagging telemetry. Journal/live stores issue supplied fetch/follow operations, schedule timers, invoke callbacks, and abort on disposal. [frontend/apps/studio/src/features/runs/TimelineView.tsx:TimelineView] [frontend/apps/studio/src/features/runs/TimelineView.tsx:TelemetryNote] [frontend/apps/studio/src/features/runs/journal.ts:JournalStore] [frontend/apps/studio/src/features/runs/liveRun.ts:LiveRunStore]
- Workflow/version hooks fetch paginated endpoint data. [frontend/apps/studio/src/features/runs/queries.ts:useWorkflowIndex] [frontend/apps/studio/src/features/runs/queries.ts:useVersions]
- Starts/disposes LiveRunStore and JournalStore, follows live updates, pushes journal events, and refreshes run/graph queries. [frontend/apps/studio/src/features/runs/RunDetailPage.tsx:RunDetail]
- Submits ep.operate with pinned request/idempotency key, invalidates the run query, announces decisions, and navigates to a new run after RERUN_AS_NEW. [frontend/apps/studio/src/features/runs/OperationDialog.tsx:DecisionForm]
- Posts payload-disclosure and payload-inspection requests and aborts superseded/unmounted work; NodePanel requests journal completion and may initiate authorized payload/database reads. [frontend/apps/studio/src/features/runs/PayloadDisclosure.tsx:PayloadDisclosureView] [frontend/apps/studio/src/features/runs/PayloadInspection.tsx:PayloadInspector] [frontend/apps/studio/src/features/runs/NodePanel.tsx:NodePanel]
- Installs a clock interval and visibility listener; writes requested clipboard values and announces their result. [frontend/apps/studio/src/features/runs/Now.tsx:NowProvider] [frontend/apps/studio/src/features/runs/CopyButton.tsx:CopyButton]
