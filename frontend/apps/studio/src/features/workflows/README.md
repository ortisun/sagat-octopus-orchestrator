# workflows

## Overview

Workflow listing and authoring UI with draft autosave, canvas/list views, validation, version comparison, and publication.

## Invariants

- Workflow names start with a lowercase letter, contain lowercase letters/digits/dashes, and have 3–64 characters. [frontend/apps/studio/src/features/workflows/WorkflowsPage.tsx:WORKFLOW_NAME]
- Canvas cards simplify above 1,000 nodes and switch to list mode above 10,000; table virtualization starts above 200 rows. [frontend/apps/studio/src/features/workflows/canvasModel.ts:FULL_UP_TO] [frontend/apps/studio/src/features/workflows/canvasModel.ts:LIST_ABOVE] [frontend/apps/studio/src/features/workflows/canvasModel.ts:canvasMode] [frontend/apps/studio/src/features/workflows/NodesTable.tsx:VIRTUAL_ABOVE]
- Unreadable node entries remain outside editable IR and are appended verbatim on serialization. [frontend/apps/studio/src/features/workflows/documentIO.ts:openDraft] [frontend/apps/studio/src/features/workflows/documentIO.ts:toWire]
- Draft saves use the known revision, reuse an idempotency key only for the same revision/document signature, serialize callers, and stop after four rounds of continuing edits. Conflicts retain both copies unless the platform already contains the attempted or prior unknown-outcome document. [frontend/apps/studio/src/features/workflows/draftSession.ts:DraftSession.#run] [frontend/apps/studio/src/features/workflows/draftSession.ts:DraftSession.#attemptSave] [frontend/apps/studio/src/features/workflows/draftSession.ts:DraftSession.#conflicted]
- Undo retains at most 100 prior documents, coalesces equal-key edits less than one second apart, and clears redo after a new commit. [frontend/apps/studio/src/features/workflows/history.ts:HISTORY_LIMIT] [frontend/apps/studio/src/features/workflows/history.ts:COALESCE_MS] [frontend/apps/studio/src/features/workflows/history.ts:commit]
- Validation requires write permission, cancels older requests after edits, ignores stale answers, and can reuse an answer when undo restores its document key. Local conflict comparison is structural and does not classify breaking changes. [frontend/apps/studio/src/features/workflows/useValidation.ts:useValidation] [frontend/apps/studio/src/features/workflows/localDiff.ts:compareDocuments]
- Publication saves and diffs first, requires acknowledgement of server-reported breaking changes, caps notes at 2,048 characters, and ties retry keys to revision/notes. Definition read, write, and publish permissions gate their corresponding operations. [frontend/apps/studio/src/features/workflows/PublishDialog.tsx:MAX_RELEASE_NOTES] [frontend/apps/studio/src/features/workflows/PublishDialog.tsx:PublishBody] [frontend/apps/studio/src/features/workflows/WorkflowEditor.tsx:WorkflowEditor] [frontend/apps/studio/src/features/workflows/WorkflowEditorPage.tsx:WorkflowEditorPage]
- Trigger kinds are manual/event/webhook/message/cron; changing kind preserves only shared fields. Durations are stored in milliseconds and reject negative, non-finite, or unsafe-integer conversions. [frontend/apps/studio/src/features/workflows/operations.ts:TRIGGER_KINDS] [frontend/apps/studio/src/features/workflows/operations.ts:setTriggerKind] [frontend/apps/studio/src/features/workflows/duration.ts:toMs]
- Preferences accept canvas/list and LR/TB only; position entries are limited to 20,000 and coordinates within ±1,000,000, with malformed storage ignored. [frontend/apps/studio/src/features/workflows/viewPrefs.ts:readView] [frontend/apps/studio/src/features/workflows/viewPrefs.ts:readDirection] [frontend/apps/studio/src/features/workflows/viewPrefs.ts:readPositions]
