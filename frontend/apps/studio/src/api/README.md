# api

## Overview

Typed same-origin REST access, Studio endpoint facade, safe errors, live run following, and generated OpenAPI contracts.

## Invariants

- Generated payload declarations distinguish structure-only-v1 from classified-v1 policies and disclosed/withheld/external/unavailable outcomes; secret is excluded from caller disclosedLevels. These are wire type constraints, not a runtime enforcement implementation. [frontend/apps/studio/src/api/schema.d.ts:components.schemas.PayloadInspection] [frontend/apps/studio/src/api/schema.d.ts:components.schemas.PayloadDisclosure] [frontend/apps/studio/src/api/schema.d.ts:components.schemas.PayloadDisclosureCaller]
- Generated errors use a closed code union, and run/runtime-node statuses are closed unions. Draft update types carry draftRevision; declared updates carry updateKey and before/after revisions plus replay status. [frontend/apps/studio/src/api/schema.d.ts:components.schemas.Error] [frontend/apps/studio/src/api/schema.d.ts:components.schemas.Run.status] [frontend/apps/studio/src/api/schema.d.ts:components.schemas.RuntimeNode.status] [frontend/apps/studio/src/api/schema.d.ts:components.schemas.UpdateDraftRequest] [frontend/apps/studio/src/api/schema.d.ts:components.schemas.DeclaredUpdateResponse]
- Secret write types accept values while Secret response types contain metadata only. PostgreSQL configuration references credentials by secretName and uses the verify-full or development-plaintext TLS union. [frontend/apps/studio/src/api/schema.d.ts:components.schemas.SetSecretRequest] [frontend/apps/studio/src/api/schema.d.ts:components.schemas.Secret] [frontend/apps/studio/src/api/schema.d.ts:components.schemas.DatabaseTls] [frontend/apps/studio/src/api/schema.d.ts:components.schemas.PostgresConnectionConfig]
- Endpoint declarations specify Idempotency-Key for deduplicated mutations and private/no-store headers on sensitive reads. Declarations describe the represented OpenAPI contract; they do not establish server execution evidence. [frontend/apps/studio/src/api/schema.d.ts:operations.createWorkflowDraft] [frontend/apps/studio/src/api/schema.d.ts:operations.startRun] [frontend/apps/studio/src/api/schema.d.ts:operations.operateRun] [frontend/apps/studio/src/api/schema.d.ts:operations.queryRun] [frontend/apps/studio/src/api/schema.d.ts:operations.inspectRunPayload] [frontend/apps/studio/src/api/schema.d.ts:operations.readDatabaseResult]
- SSE accepts LF/CR/CRLF across chunk boundaries, strips the initial BOM, ignores comments and NUL-containing IDs, joins data lines, defaults empty event names to message, and dispatches only events containing data. [frontend/apps/studio/src/api/sse.ts:SseParser.push] [frontend/apps/studio/src/api/sse.ts:SseParser.#line]
- readSse flushes the decoder at EOF and removes its abort listener in finally. Studio-facing aliases reuse generated components schemas rather than a separate handwritten wire representation. [frontend/apps/studio/src/api/sse.ts:readSse] [frontend/apps/studio/src/api/types.ts:Schemas]
- Generated operations describe trace/request headers and typed success/error response variants; they are contract types, not implementation evidence. [frontend/apps/studio/src/api/schema.d.ts:operations.setPublicationPolicy] [frontend/apps/studio/src/api/schema.d.ts:operations.recordScriptRunnerIncident]
- path percent-encodes interpolated segments. ApiClient.url accepts only absolute same-origin paths and rejects protocol-relative syntax, backslashes, and double-dot traversal. [frontend/apps/studio/src/api/client.ts:path] [frontend/apps/studio/src/api/client.ts:ApiClient.url]
- Requests omit cookies, reject redirects, disable caching, suppress referrers, and attach bearer/namespace headers only when present. Every non-GET gets an idempotency key; supplied keys can survive retries. [frontend/apps/studio/src/api/client.ts:ApiClient.headers] [frontend/apps/studio/src/api/client.ts:ApiClient.open] [frontend/apps/studio/src/api/client.ts:ApiClient.request]
- Ordinary requests default to a 30-second timeout; streams have no client timeout. UNAUTHENTICATED invokes the session-ending callback. [frontend/apps/studio/src/api/client.ts:DEFAULT_TIMEOUT_MS] [frontend/apps/studio/src/api/client.ts:ApiClient.open] [frontend/apps/studio/src/api/client.ts:ApiClient.failure]
- Error parsing accepts known codes, clips messages/remediation to 300 characters, validates 32-hex trace IDs and closed-form reasons, and caps numeric Retry-After at one minute. [frontend/apps/studio/src/api/errors.ts:errorFromResponse] [frontend/apps/studio/src/api/errors.ts:retryAfterMs] [frontend/apps/studio/src/api/errors.ts:ApiError]
- SSE/polling resume from the last projection sequence. Repeated stream failures switch to polling before another SSE attempt; terminal status stops following. Jittered reconnect backoff ranges from 500 ms to 15 seconds. [frontend/apps/studio/src/api/follow.ts:followRun] [frontend/apps/studio/src/api/follow.ts:isTerminal] [frontend/apps/studio/src/api/follow.ts:MIN_BACKOFF_MS] [frontend/apps/studio/src/api/follow.ts:MAX_BACKOFF_MS]

## Side Effects

- Acquires/consumes a stream reader, installs an abort listener, and cancels the reader on abort or cleanup. [frontend/apps/studio/src/api/sse.ts:readSse]
- Performs fetches, creates timeout/abort controllers, and invokes unauthenticated callbacks; the endpoint facade issues typed reads/mutations. [frontend/apps/studio/src/api/client.ts:ApiClient.open] [frontend/apps/studio/src/api/client.ts:ApiClient.request] [frontend/apps/studio/src/api/endpoints.ts:endpoints]
- Opens/consumes SSE, polls graph changes, schedules retry/poll timers, emits state/change callbacks, and aborts stream/poll/sleep work on close. [frontend/apps/studio/src/api/follow.ts:followRun]
