# Tasks: Per-field payload classification

**Input**: `spec.md`, `plan.md`, `research.md`, `data-model.md`, `contracts/README.md`, `quickstart.md`.
**Scope**: all of ADR-0033 for run payloads (input, result, step outputs). Nothing is built; **no task is
ticked**, including T016-001, which closes when this specification is merged. A task is ticked only with
the evidence that closes it (a named test that passed, a command and its result). Tests precede
implementation within each phase. IDs are feature-scoped per the constitution. `[P]` marks tasks that
touch disjoint files and can run in parallel; `[USnn]` ties a task to a user story.

**Blocking decisions**: T016-002 collects the owner's answers to P1-P4 of `research.md`. P1 (the grant
mechanism) blocks T016-032 to T016-037; if the owner picks another option, section 2.2 of
`contracts/README.md` and `data-model.md` section 3.2 are rewritten first. P2 blocks nothing in this
increment (the recommendation leaves the event inbox as it is).
