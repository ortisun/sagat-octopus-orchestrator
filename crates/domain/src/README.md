# crates/domain/src

## Overview

Framework-free domain boundary for identity, audit, workflow/execution models, policies, integration vocabulary and planners/validators. Storage, transport, process and serialization adapters live elsewhere; local identifier generation is explicitly nondeterministic.

## Invariants

- The crate's production dependency list excludes web/SQL/broker/serialization adapters. Scoped constructors derive tenant from Principal, authorize required permissions and reject foreign parents; trusted restore methods deliberately bypass normal construction checks. [../Cargo.toml:dependencies] [identity.rs:Principal::authorize] [identity.rs:Workspace::create] [identity.rs:Namespace::create] [definition.rs:Workflow::create] [definition.rs:Workflow::restore]
- Audit construction inherits principal identity or fixed system actors, but with_reason does not validate secret/PII content. SecretValue is 1..=16 KiB, redacted/zeroizing and equal-length comparisons avoid early exit; associated data binds tenant/namespace/name/row/key. [audit.rs:AuditRecord::by] [audit.rs:AuditRecord::with_reason] [secrets.rs:SecretValue::new] [secrets.rs:SecretValue::eq] [secrets.rs:associated_data]
- Classification defaults unmarked values to PII. Audience::new enforces pii implies internal, but its public fields permit bypass through struct literals. Egress defaults deny and separates destination from address checks; prohibited special address classes cannot be allowlisted. [classification.rs:Level] [classification.rs:Audience::new] [classification.rs:Audience] [egress.rs:EgressPolicy::deny_all] [egress.rs:EgressPolicy::check_destination] [egress.rs:EgressPolicy::check_address] [egress.rs:AddressClass::never_allowed]
- Database limits are positive/bounded and intersect by minimum. Managed execute nodes are no-retry, high-risk and irreversible, and managed activities cannot be forged or freely combined with structured bodies/continuations. [database.rs:DatabaseLimits::validate] [database.rs:DatabaseLimits::intersect] [workflow.rs:Node::database] [workflow.rs:check_node] [workflow.rs:WorkflowDefinition::new_structured_inner]
- Endpoint limits bound TTL/skew/body/rate and require dedupe >= twice skew plus 60 seconds; connector server/rate bounds are checked. SQS domain construction delegates to TargetUrl's HTTP(S) parser, so its descriptive HTTPS wording alone is not enforcement. [events.rs:EndpointLimits::new] [events.rs:checked_dedupe_ttl] [connectors.rs:parse_servers] [connectors.rs:check_rate] [connectors.rs:ConnectorSettings::sqs] [outbound.rs:TargetUrl::parse]
- Outbound classifies 2xx done, 408/425/429/5xx retryable and other responses dead; retry-after/backoff/attempts are bounded. Quota scope/metadata/ceilings are closed and precedence is namespace then tenant then ceiling; iteration concurrency defaults disabled. [outbound.rs:judge_response] [outbound.rs:delivery_backoff] [outbound.rs:out_of_attempts] [quota.rs:validate] [quota.rs:resolve]
- Script values/limits/policies/status transitions are bounded and closed. Redaction recognizes selected known values/credential patterns, not encoded exfiltration. Publication excludes requester/editor decisions, allows one decision per subject, makes rejection terminal and rechecks approval count before publish. [scripts.rs:Source::parse] [scripts.rs:Limits::new] [scripts.rs:Policy::within] [scripts.rs:VersionStatus::can_become] [scripts.rs:redact] [versioning.rs:PublicationRequest::decide] [versioning.rs:PublicationRequest::publish]
- Workflow construction validates unique/reachable/acyclic local graphs, targets and resource bounds, closed disjoint regions, body terminal returns/nonrecursive references and depth. Derived companion IDs use reserved forms. Saga plans deterministically reverse dependencies and preserve unknown outcomes. Shape validation alone does not enable execution. [workflow.rs:DefinitionGraph::new] [workflow.rs:check_body_return] [workflow.rs:check_body_references] [workflow.rs:parallel_regions] [workflow.rs:saga_regions] [workflow.rs:derive_companions] [saga.rs:compensation_plans] [saga.rs:ReconcileVerdict]

## Side Effects

- Most operations allocate/validate/classify/plan or mutate in-memory aggregates without database/network/filesystem/process I/O. UUID wrapper generate uses UUIDv7 generation state, EndpointId::random uses UUIDv4 and audit construction generates IDs; these are nondeterministic local operations. [saga.rs:compensation_plans] [sharding.rs:plan] [macros.rs:uuid_id] [events.rs:EndpointId::random] [audit.rs:AuditRecord::by]
- PublicationRequest and ShardSet mutate memory; workflow constructors allocate graphs and synthesize companions without executing workflows. SecretValue zeroizes on drop; SecretCipher declares a port rather than implementing provider cryptography here. [versioning.rs:PublicationRequest::approve] [sharding.rs:ShardSet::insert] [workflow.rs:DefinitionGraph::new] [workflow.rs:derive_companions] [secrets.rs:SecretValue] [secrets.rs:SecretCipher]
