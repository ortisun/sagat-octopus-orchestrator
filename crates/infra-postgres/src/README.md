# crates/infra-postgres/src

## Overview

PostgreSQL authority adapter implementing application storage ports, guarded transactions, durable journal/projections, quotas, receipts, audit and outbox. Cache-backed collection ports are active for their supported subset; exact ChildRoot capacity and narrow proof ports remain separate dormant boundaries.

## Invariants

- Approval writes validate audit scope/action/actor/time, lock member chain before run, verify scheduler authority using the database clock, cross-check journal/projection/step state and use status/run CAS. Replay retains the receipt; current membership controls authorization. [approval_progress.rs:check_audit] [approval_progress.rs:lock_run_whatever_its_state] [approval_progress.rs:check_scheduler_fence] [approval_progress.rs:verify_projection] [approval_progress.rs:current_principal]
- Binding replacement takes an exclusive subject advisory lock while attempt commits share it; replacement locks sessions before expiring uncovered work. Blob reserve serializes pending-count admission and binds exact output identity; commit requires matching uploaded metadata and ownership. [bindings.rs:hold_worker_binding] [bindings.rs:BindingStore] [blobs.rs:reserve] [blobs.rs:commit] [blobs.rs:commit_input]
- Breaker row locks serialize outcomes and half-open probes. Blob deletion claims precede provider deletion, committed blobs are ineligible and unconfirmed PUT evidence can delay final deletion. [breaker.rs:record_failure] [breaker.rs:admit] [blobs.rs:finish_delete]
- Capacity candidates are hints only. Exact dormant transfer/finish locks chain → exact run → capacity header with NOWAIT, rechecks member/scheduler authority and refuses stale identities rather than redirecting to a new head. Possession is not a runnable/lease permit; no creator, scheduler caller, general nesting or workload acceptance follows. [capacity_discovery.rs:decode] [capacity_transfer.rs:apply] [capacity_finish.rs:apply]
- Capacity replay requires exact original key/fingerprint/kind/scope/member/head/counters. Fresh writes CAS revisions/epochs and retain immutable receipts; uncertain commits return CommitOutcomeUnknown for original-key reconciliation. Vacate requires held possession/quiescence; Acquire changes possession only; Finish requires terminal matching chain/run finality. [capacity_transfer.rs:replay] [capacity_transfer.rs:transfer] [capacity_transfer.rs:apply] [capacity_finish.rs:replay] [capacity_finish.rs:finality] [capacity_finish.rs:finish_transaction]
- Chain handoff locks chain, immutable parent identity guard and head/link, then checks scheduler authority, exact revisions, limits/quiescence, payload digests, quota and supported entry shape. Predecessor/successor/head/audit/outbox changes share the transaction; only activity entries receive task.ready hints. [chain_progress.rs:lock_chain] [chain_progress.rs:hold_parent] [chain_progress.rs:check_fence] [chain_progress.rs:typed_segment_blocker] [chain_progress.rs:retain_payload] [chain_progress.rs:continue_evaluated]
- Collection-output inspection requires exact successful root ForEach ownership/counters, clean work/drain state, matching payload metadata and paired finish/routing journal evidence. [collection_outputs.rs:inspect] [collection_outputs.rs:verify_journal]
- Connector checkpoints advance by CAS with accepted/duplicate/set-aside admission; dead letters are bounded and duplicate positions are not recounted. Rate admission locks policy and ordered buckets, dry-runs all buckets before debit and enforces retention ceilings. [connectors.rs:move_checkpoint] [connectors.rs:ConnectorRuntime] [content_usage.rs:take_event_rate] [content_usage.rs:lock_bucket] [content_usage.rs:check_event_retention]
- Connection mutation requires current DatabaseManage, exact revision/request replay, OpenBao secrets and dev-only plaintext. Result selection checks current RunRead/DatabaseResultRead under locks and exact committed blob provenance; provider work is outside the transaction. [database.rs:ConnectionStore] [database_results.rs:selected]
- Mutation entry uses safe transactions and tenant-qualified identity. Run entry locks applicable chain before run; child reservation locks parent then the tree advisory key, and scheduler checks sample the database clock after shard lock. [pool.rs:BeginSafely] [execution.rs:lock_member_chain] [execution.rs:claim_reservation] [execution.rs:locked_scheduler_time_sql]
- Persisted version plus event count must equal state version, journal sequences advance monotonically and run updates use the loaded revision CAS. [execution.rs:PgRunTx::persist] [execution.rs:PgRunTx::persist_scoped_addressed] [execution.rs:PgRunTx::upsert_scoped_instance]

[execution.rs:PgRunTx::lease_unexpired] [execution.rs:PgRunTx::lease_matches_instance] [execution.rs:current_worker_authorized] [execution.rs:check_database_replay] [execution.rs:PgRunTx::record_scoped_event_delivery] [execution.rs:PgRunTx::commit]

[execution.rs:load_collections] [execution.rs:load_loops] [execution.rs:load_scope_sagas] [execution.rs:load_chain] [execution.rs:PgRunTx::charge_logical_output_bytes]

- Migrate executes embedded SQL. - Chain transitions write chain/segment/link/run/step/state/payload/journal/telemetry/audit/outbox rows and finalization fans out outbound obligations. [chain_progress.rs:initialize_chain_in_transaction] [chain_progress.rs:continue_evaluated] [collection_outputs.rs:inspect] [collection_outputs.rs:hydrate_missing]

[connectors.rs:ConnectorStore] [connectors.rs:ConnectorRuntime] [content_usage.rs:apply_content_delta] [database.rs:ConnectionStore] [database_results.rs:DatabaseResultStore]
- Definition/operation methods write workflow versions, plans/triggers/declarations/state/update receipts, payloads/dedupe/publication and audit rows. [definitions.rs:publish] [declared_operations.rs:commit_applied] [events.rs:admit_within] [dispatch.rs:retry_event] [event_payloads.rs:finish] [egress.rs:put_egress_policy]
